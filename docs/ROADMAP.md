# Roadmap

## v0.1 — Research foundation

- protocol definition;
- safety and non-claims boundary;
- JSON transition schema;
- canonical example;
- deterministic validator and tests;
- ecosystem bridge;
- X-Cell outreach draft.

## v0.2 — Metadata feasibility

- inspect the released X-Atlas/Pisces metadata contract;
- identify usable phase, timepoint, duration, batch, and replicate fields;
- produce a data-availability matrix;
- document leakage risks and missing variables.

## v0.3 — Baseline benchmark

- build a static-state baseline;
- add one cell-cycle phase token;
- preregister splits and metrics;
- run ablations and calibration checks;
- publish negative results as first-class outcomes.

## v0.4 — X-Cell adapter

- integrate the public inference API when available;
- keep all adapter behavior versioned and reproducible;
- emit Kairos transition records from predictions;
- attach exact code and data provenance.

## v0.5 — Trajectory extension

- add multiple response horizons;
- distinguish Chronos timestamps from Kairos state readiness;
- evaluate recovery and identity-preservation proxies;
- explore sequence models only after the single-step benchmark succeeds.

## v1.0 criterion

A stable research release requires an independently reproducible phase-conditioned benchmark, explicit uncertainty, provenance, negative tests, and no unsupported biological or therapeutic claims.
